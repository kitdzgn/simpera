# SIMPERA — Sistem Pengumpulan Perangkat Ajar Digital

Aplikasi web manajemen pengumpulan dan verifikasi perangkat ajar guru berbasis kelas.

## Fitur Utama
- **Portal Guru per Kelas:** Unggah dokumen perangkat ajar berformat `.pdf` atau `.docx` sesuai kategori.
- **Dashboard Admin:** Kelola kategori & baris administrasi, generate akun guru otomatis, verifikasi dokumen, dan kirim catatan revisi.
- **Pengingat WhatsApp & Tenggat Waktu:** Deteksi otomatis guru yang belum melengkapi perangkat ajar dan kirim pengingat via WhatsApp.
- **Sinkronisasi Database GitHub:** Ekspor dan sinkronisasi data ke `database.json` langsung dari dashboard admin.

## Struktur File
- `index.html` — Aplikasi utama (Login, Dashboard Guru, & Dashboard Admin).
- `database.json` — Penyimpanan data aplikasi.
